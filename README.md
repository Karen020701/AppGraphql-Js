# GraphQL project with Node.js and Apollo Server

This is a basic project for a GraphQL server using Node.js and Apollo Server. The server exposes a simple query that returns a hello message.

## Clone the repository

```bash
git clone https://github.com/Karen020701/AppGraphql-Js.git
```
## Installing dependencies
This project uses the following dependencies:

*Apollo-server*: A server to implement GraphQL in Node.js.
*Graphql*: The main GraphQL library.
You can also use the following command to install the dependencies:
```bash
npm install
```

## Server
The server is started using
```bash
node server.js
```

Once executed, it goes to the URL http://localhost:4000/
